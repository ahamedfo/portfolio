# ahamedfo.github.io/portfolio

Personal site for Ahamed Fofana. Applied AI engineering, cybersecurity, and multi-agent research.

Static Next.js export, deployed to GitHub Pages from `main`.

```bash
npm install
npm run dev     # http://localhost:3000/portfolio
npm run build   # static export into ./out
```

See [CONTENT.md](CONTENT.md) for how the content is structured, how to add a case
study or an approved testimonial, the deployment contract, and the checks to run
before publishing.

Private source material, approval records, and the claims checklist are kept
outside this repository and must stay that way.
